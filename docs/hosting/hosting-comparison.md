
# Static Website Hosting Comparison

| Feature | GitHub Pages | Netlify | Vercel |
|---|---|---|---|
| Starting price | Free tier | Free tier | Free tier |
| Git integration | Yes | Yes | Yes |
| Private repository support | Plan-dependent | Yes | Yes |
| Custom domain | Yes | Yes | Yes |
| Deployment | GitHub Actions | Automatic | Automatic |
| Ease of use | Easy | Very easy | Easy |
| Static documentation | Suitable | Suitable | Suitable |

## Final Decision

Netlify is selected for publishing the
Aura Workforce Security Hub.

The GitHub repository will remain private,
while only sanitized static documentation
will be published.

Pricing, usage limits and commercial-use
conditions must be checked against the
current provider plans.
