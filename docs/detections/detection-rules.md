
# Security Detection Documentation

## Detection 1: Repeated Failed Logins

Objective: Identify unusual authentication failures.

Severity: Medium

Recommended action: Review authentication
events and investigate suspicious patterns.

## Detection 2: Privileged Access Changes

Objective: Monitor unexpected permission changes.

Severity: High

Recommended action: Review authorization records
and validate approved administrative activity.

## Detection 3: Unusual Account Activity

Objective: Identify unexpected account behaviour.

Severity: Medium

Recommended action: Review relevant security logs.
